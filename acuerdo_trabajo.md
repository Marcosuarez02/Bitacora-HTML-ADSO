## 2. Compromisos y Acuerdos Técnicos

1. **Uso Exclusivo de HTML Puro y Semántico:**
   - No se utilizarán etiquetas obsoletas (`<center>`, `<font>`, `<table>` para maquetación general).
   - Estructuración con `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>` y `<table>` semántico (`<thead>`, `<tbody>`, `<th>` con atributo `scope`).
2. **Accesibilidad Total (WCAG):**
   - Idioma declarado en `lang="es"`.
   - Atributos `alt` descriptivos en todas las imágenes.
   - Enlaces descriptivos (sin textos genéricos como "clic aquí").
   - Contraste y semántica apta para lectores de pantalla.
3. **Navegabilidad Fluida:**
   - Las tres vistas (`index.html`, `reglas.html`, `trazabilidad.html`) estarán intercomunicadas mediante un menú `<nav>` idéntico y consistente.
4. **Desarrollo y Entrega Individual:**
   - Aunque la planeación semántica se acordó en consenso grupal, cada integrante codificará de manera autónoma sus archivos, mantendrá su propio repositorio en GitHub y publicará su sitio en GitHub Pages.
